# Платформа Аналітики Новинних Фідів

## 🎯 Огляд Проекту

Комплексна аналітична та рекламна платформа на базі Node.js, що поєднує парсинг RSS фідів, аналітику в реальному часі, програматичну рекламу та подвійну архітектуру баз даних для оптимальної продуктивності та масштабованості.

---

## 🚀 CI/CD та Конвеєр Розгортання

### **GitHub Actions Workflows**
Проект включає автоматизований CI/CD конвеєр з двома основними workflow:

#### **1. Безперервна Інтеграція (ci.yml)**
```yaml
# .github/workflows/ci.yml
name: CI

on:
  pull_request:
    branches: [main, master]    # Запускається при PR до main/master
  push:
    branches: [main, master]    # Запускається при прямих push

jobs:
  lint-and-build:
    name: Lint & Build PR check
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4        # Завантаження коду репозиторію
      - name: Setup Node.js              # Встановлення Node.js 20
        uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Install dependencies       # Встановлення npm пакетів
        run: npm ci
      - name: Run Biome lint             # Перевірка якості коду
        run: npx biome lint src/
      - name: Build TypeScript           # Компіляція TypeScript
        run: npm run build
```

**Призначення та Переваги:**
- **Якість Коду:** Забезпечує дотримання всім кодом однакового стилю та стандартів
- **Типобезпека:** Перевіряє компіляцію TypeScript перед злиттям
- **Швидкий Зворотний Зв'язок:** Розробники отримують миттєвий відгук щодо PR
- **Попередження Проблем:** Виявляє помилки перед потраплянням у продакшн

#### **2. Конвеєр Розгортання (fly-deploy.yml)**
```yaml
# .github/workflows/fly-deploy.yml
name: Fly Deploy

on:
  push:
    branches: [main]              # Розгортання лише з гілки main

jobs:
  deploy:
    name: Deploy app
    runs-on: ubuntu-latest
    concurrency: deploy-group     # Запобігає одночасним розгортанням
    steps:
      - uses: actions/checkout@v4        # Отримання останнього коду
      - uses: superfly/flyctl-actions/setup-flyctl@master  # Налаштування Fly.io CLI
      - run: flyctl deploy --remote-only # Розгортання на Fly.io
        env:
          FLY_API_TOKEN: ${{ secrets.FLY_API_TOKEN }}  # Безпечний токен розгортання
```

**Особливості Розгортання:**
- **Автоматичне Розгортання:** Кожне злиття в main запускає розгортання
- **Віддалена Збірка:** Додаток збирається на інфраструктурі Fly.io
- **Контроль Конкурентності:** Запобігає перекриттю розгортань
- **Безпечна Автентифікація:** Використовує GitHub secrets для API токенів

```
Кроки Детально:

2. CI перевіряє якість коду та збірку → Надає миттєвий відгук
3. PR злито в main → Запускається workflow розгортання
4. Fly.io збирає та розгортає → Додаток стає доступним
5. Перевірки здоров'я підтверджують → Користувачі отримують оновлений додаток
```

### **Конфігурація Розгортання**
- **Платформа:** Fly.io PaaS (Platform as a Service)
- **Стратегія Збірки:** Віддалені Docker збірки для консистентності
- **Масштабування:** Автоматичне масштабування на основі трафіку
- **Регіони:** Глобальне розгортання з крайовими локаціями
- **SSL/TLS:** Автоматичні HTTPS сертифікати

### **Переваги Конвеєра**
- **Швидкий Відгук:** Розробники миттєво дізнаються чи проходить код перевірки якості
- **Автоматизована Якість:** Не потрібно ручного втручання для валідації коду
- **Нульовий Час Простою:** Процес розгортання забезпечує безперервну доступність
- **Можливість Відкату:** Легкий повернення до попередніх версій при виникненні проблем
- **Безпека:** Управління секретами через зашифровані змінні GitHub

## 📋 Архітектура Схем та Валідація

### **Реалізація JSON Schema**
Проект використовує чистий JSON Schema для всієї валідації API та документації:

```typescript
// Приклад: getNews.schema.ts
export const getNewsSchema = {
  tags: ["news"],                    // Групування Swagger
  summary: "Get all news for user",  // Опис API endpoint
  querystring: {
    type: "object",                  // JSON Schema валідація
    properties: {
      email: {
        type: "string",
        format: "email",             // Вбудована валідація формату
        description: "User email",   // Swagger документація
        examples: ["user@example.com"] // API приклади
      }
    }
  },
  response: {
    200: {                          // Схеми HTTP статус кодів
      type: "object",
      properties: { ... }
    }
  }
} as const;                         // TypeScript const assertion
```

### **Переваги та Використання Схем**
- **Автоматична Валідація:** Fastify валідує всі запити/відповіді відповідно до схем
- **TypeScript Інтеграція:** `@fastify/type-provider-json-schema-to-ts` генерує типи автоматично
- **Swagger Документація:** Схеми генерують інтерактивну документацію API
- **Генерація Клієнтського Коду:** OpenAPI специфікації можуть генерувати клієнтські SDK
- **Безпека Runtime:** Ловить неправильні дані перед тим, як вони досягнуть бізнес-логіки

### **Патерн Структури Схем**
Кожен файл схеми містить:
- **tags:** Групування Swagger UI
- **summary/description:** Зрозуміла документація
- **querystring/body/params:** Схеми валідації запитів
- **response:** Формат відповіді для кожного HTTP статус коду
- **examples:** Зразкові дані для тестування та документації

## 🛠️ Основні Технології та Бібліотеки

### **Backend Фреймворк**
- **Fastify** - Високопродуктивний Node.js веб-фреймворк
  - **Чому:** В 3 рази швидший за Express, вбудована підтримка TypeScript, екосистема плагінів
  - **Переваги:** Валідація схем, серіалізація, хуки життєвого циклу, авто-документація

### **Технології Баз Даних**
- **MongoDB + Prisma ORM** - Основна транзакційна база даних з типобезпечним ORM
  - **Чому:** Документо-орієнтоване сховище ідеальне для гнучких схем, відмінна TypeScript інтеграція
  - **Переваги:** Запити в реальному часі, ACID транзакції, автоматичні міграції, типобезпечні операції БД
  - **Функції Prisma:** Авто-генерований клієнт, інтроспекція БД, система міграцій, оптимізація запитів

- **ClickHouse** - Високопродуктивна колонкова аналітична база даних
  - **Чому:** Колонкова БД оптимізована для аналітичних навантажень, ефективно обробляє мільярди записів
  - **Переваги:** Суб-секундні аналітичні запити, автоматичне стиснення, управління TTL, горизонтальне масштабування
  - **Випадки Використання:** Дані часових рядів, аналітика подій, агрегації, дашборди звітності

### **Автентифікація та Безпека**
- **JWT (@fastify/jwt)** - Система автентифікації на основі токенів
  - **Чому:** Stateless автентифікація ідеальна для розподілених систем та мікросервісів
  - **Переваги:** Без серверного зберігання сесій, масштабується на декількох інстансах, безпечна токенна авт.
  - **Функції:** Автоматична валідація токенів, налаштовуване закінчення, підтримка refresh токенів

- **Bcrypt (fastify-bcrypt)** - Криптографічна бібліотека хешування паролів
  - **Чому:** Індустріальний стандарт адаптивного алгоритму хешування, розроблений спеціально для безпеки паролів
  - **Переваги:** Захист від rainbow table атак, налаштовувана обчислювальна складність, генерація солі
  - **Безпека:** Зберігає хеші паролів замість відкритого тексту, роблячи витоки даних менш катастрофічними
  - **Алгоритм:** Використовує blowfish шифр з адаптивним фактором складності, який можна збільшувати з покращенням апаратури

### **Валідація Схем та Типи**
- **TypeScript** - Система статичної типізації для JavaScript
  - **Чому:** Виявлення помилок на етапі компіляції, краща підтримка IDE, покращена підтримуваність коду
  - **Переваги:** Зменшені помилки runtime, покращений досвід розробника, краща підтримка рефакторингу

- **JSON Schema** - Стандартний формат валідації для API контрактів
  - **Чому:** Індустріальна стандартна мова визначення схем з відмінною підтримкою інструментів
  - **Переваги:** Авто-генерована документація, валідація runtime, генерація клієнтського коду
  - **Використання:** Всі API endpoints використовують JSON Schema для валідації запитів/відповідей та Swagger документації

- **@fastify/type-provider-json-schema-to-ts** - Автоматична TypeScript інтеграція
  - **Чому:** Безшовна інтеграція між JSON Schema та TypeScript типами у Fastify
  - **Переваги:** Типобезпека без дублювання коду, автоматичне виведення зі схем

### **Планування та Фонові Завдання**
- **ToadScheduler** - TypeScript-нативна бібліотека планування завдань
  - **Чому:** Легкий, надійний cron-подібний планувальник, побудований спеціально для Node.js та TypeScript
  - **Переваги:** Ефективне управління завданнями з точки зору пам'яті, легке налагодження, гнучкі патерни планування
  - **Функції:** Cron вирази, інтервальні завдання, одноразові роботи, обробка помилок, постійність завдань

### **Обробка Файлів та Статичні Ресурси**
- **@fastify/multipart** - Завантаження файлів
  - **Чому:** Нативна Fastify інтеграція, підтримка потоків
  - **Переваги:** Ефективні завантаження з точки зору пам'яті, обмеження розміру, валідація

- **@fastify/static** - Сервінг статичних файлів
  - **Чому:** Оптимізована доставка статичних файлів з кешуванням та стисненням
  - **Переваги:** Gzip стиснення, ETag заголовки, перегляд директорій, користувацькі заголовки

### **Обробка RSS Фідів**
- **xml2js** - Надійний парсер XML в JavaScript об'єкти
  - **Чому:** Зріла XML парсинг бібліотека з комплексним набором функцій та відмінною обробкою помилок
  - **Переваги:** Налаштовувані опції парсингу, грациозно обробляє невірно сформований XML, підтримка атрибутів та namespace
  - **Функції:** Користувацькі процесори, обробка масивів, трансформація значень, підтримка потоків

- **cheerio** - Серверна бібліотека маніпуляції HTML/XML DOM
  - **Чому:** jQuery-подібний API для серверного парсингу та маніпуляції HTML без накладних витрат браузера
  - **Переваги:** Швидке витягування контенту, знайомі CSS селектори, санітізація HTML, легкий
  - **Випадки Використання:** Веб-скрапінг, витягування контенту, очищення HTML, обхід та модифікація DOM

### **API Документація**
- **@fastify/swagger** - Генерація OpenAPI 3.0 специфікації
  - **Чому:** Автоматична документація API зі схем та маршрутів
  - **Переваги:** Жива документація, валідація схем, генерація клієнтського коду

- **@fastify/swagger-ui** - Інтерактивна документація API
  - **Чому:** Красивий веб-інтерфейс для тестування та дослідження API
  - **Переваги:** Живе тестування API, підтримка автентифікації, можливості експорту

### **HTTP Утиліти та CORS**
- **@fastify/sensible** - HTTP утиліти та розумні за замовчуванням для Fastify
  - **Чому:** Надає стандартні HTTP статус коди, утиліти обробки помилок та загальні HTTP патерни
  - **Переваги:** Консистентні відповіді помилок, корисні HTTP утиліти, кращий досвід розробника
  - **Функції:** HTTP статус помічники, об'єкти помилок, декоратори запитів, утиліти відповідей

- **@fastify/cors** - Cross-Origin Resource Sharing middleware
  - **Чому:** Необхідний для веб-додатків, які потребують безпечної обробки cross-origin запитів
  - **Переваги:** Налаштовувані origin, підтримка credentials, обробка preflight, відповідність безпеці
  - **Функції:** Валідація origin, підтримка користувацьких заголовків, обробка credentials, оптимізація preflight

### **Кешування та Управління Пам'яттю**
- **node-cache** - Високопродуктивна бібліотека кешування в пам'яті
  - **Чому:** Просте та ефективне кешування в пам'яті з автоматичним очищенням та підтримкою TTL
  - **Переваги:** Налаштовуваний TTL, обмеження пам'яті, закінчення, керовані подіями, відстеження статистики
  - **Функції:** Зберігання ключ-значення, автоматичне збирання сміття, метрики попадань/промахів кешу, виявлення клонів
  - **Випадки Використання:** Кешування відповідей API, зберігання сесій, буферизація тимчасових даних, оптимізація продуктивності

### **RSS та Веб-скрапінг**
- **xml2js** - Парсинг XML для RSS фідів
  - **Чому:** Надійна конвертація XML в JSON
  - **Переваги:** Обробляє невірно сформований XML, налаштовуваний парсинг

- **Cheerio** - Серверний парсинг HTML
  - **Чому:** jQuery-подібний синтаксис для серверної маніпуляції DOM

```
src/
```

### **Патерн Структури Модуля**
Кожен бізнес-домен слідує консистентній структурі:
```
modules/{domain}/
├── routes/           # API endpoints
├── schemas/          # Схеми валідації
├── services/         # Бізнес-логіка
├── types/            # Типи специфічні для домену
└── utils/            # Утилітарні функції
```

### **Ключові Переваги Архітектури**

#### **1. Плагін-Орієнтована Архітектура**
- **Розділення Концернів:** Кожен плагін обробляє специфічну функціональність
- **Управління Залежностями:** Явні залежності плагінів забезпечують правильний порядок завантаження
- **Тестованість:** Ізольовані плагіни легше тестувати юніт-тестами
- **Повторне Використання:** Плагіни можна ділити між проектами

#### **2. Подвійна Стратегія Баз Даних**
- **MongoDB:** CRUD операції в реальному часі, сесії користувачів, потреби негайних даних
- **ClickHouse:** Аналітика, агрегації, дані часових рядів, звітність
- **Переваги:** Оптимальна продуктивність для різних типів навантажень

#### **3. Memory Cache + Пакетна Обробка**
- **Продуктивність:** Зменшує навантаження на БД через інтелектуальне кешування
- **Надійність:** Дані зберігаються в MongoDB негайно, аналітика в кінцевому підсумку консистентна
- **Масштабованість:** Пакетні операції обробляють сценарії високої пропускної спроможності

#### **4. Типобезпечна Розробка**
- **Валідація Часу Компіляції:** TypeScript ловить помилки перед runtime
- **Валідація Runtime:** JSON Schema забезпечує дотримання API контракту
- **Авто-документація:** Схеми генерують Swagger документацію автоматично

## 🌐 Огляд API Endpoints

### **Endpoints Автентифікації**
- `POST /auth/register` - Реєстрація користувача
- `POST /auth/login` - Автентифікація користувача
- Токен-орієнтована автентифікація з JWT

### **Управління Новинними Фідами**
- `GET /feed` - Отримання даних RSS фіду
- `POST /feed` - Додавання нового RSS фіду
- `PUT /feed/:id` - Оновлення конфігурації фіду
- `DELETE /feed/:id` - Видалення фіду

### **Новинний Контент**
- `GET /news` - Список новинних статей з пагінацією
- `GET /news/:id` - Отримання специфічної новинної статті
- `DELETE /news/:id` - Видалення новинної статті
- Розширені можливості фільтрації, сортування та пошуку

### **Програматична Реклама**
- `POST /ads/bid` - Endpoint торгів в реальному часі
  - Фільтрація креативів за розміром, гео, частотним кепінгом
  - Валідація bid floor
  - Сервінг реклами в реальному часі

### **Аналітика та Події**
- `POST /ads/event/:type` - Відстеження рекламних подій
  - Підтримувані типи: click, impression, view, close, тощо
  - Подвійне зберігання: MongoDB + ClickHouse кеш

### **ClickHouse Аналітика**
- `GET /clickhouse/health` - Перевірка здоров'я бази даних
- `GET /clickhouse/events` - Сирі дані подій з фільтрацією
- `GET /clickhouse/analytics` - Агрегована аналітика
  - Групування за: день, година, тип_події, джерело
  - Фільтрація діапазону дат, пагінація

### **Event Grid та Статистика**
- `POST /statistics/grid` - Дані подій для UI грідів
- `GET /settings/grid` - Налаштування грідів користувача
- `POST /settings/grid` - Збереження конфігурації гріду

### **Управління Креативами (SSR)**
- `GET /ssr/` - Форма завантаження креативів (React SSR)
- `POST /ssr/upload` - Завантаження файлів для креативів
- `GET /ssr/creatives` - Список креативів користувача

### **Налаштування Користувача**
- `GET /settings/grid/:viewName` - Отримання збережених налаштувань гріду
- `POST /settings/grid` - Створення конфігурації гріду
- `PUT /settings/grid/:id` - Оновлення налаштувань
- `DELETE /settings/grid/:id` - Видалення налаштувань
